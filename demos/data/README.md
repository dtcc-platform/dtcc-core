# Bundled demo data

Small, stable inputs used by the demos so they can run without downloading from
fragile external URLs.

## `DenHaag_01.city.json.zip`

A CityJSON tile of The Hague (Den Haag), Netherlands, in LOD2. Used by
`demos/view_cityjson.py`, `demos/build_view_cityjson.py`, and
`demos/build_cityjson_surface_mesh.py`.

- Source: [3D city model of the Netherlands](https://3dbag.nl/) / TU Delft 3D
  geoinformation open data (CityJSON v2.0).
- Licence: CC BY 4.0.
- This is the same file already vendored at
  `tests/data/cityjson/DenHaag_01.city.json.zip`.
