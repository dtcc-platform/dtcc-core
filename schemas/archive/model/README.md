# Historical standard definitions

These schema 0.1.0, 0.2.0, 0.3.0 and 0.4.0 files are unchanged snapshots from the model
overhaul and are not bundled runtime schemas. Versions 0.1.0 and 0.2.0 use the
former camelCase property spellings; 0.3.0 introduced snake_case.
The current snake_case contract is
[model 0.5.0](../../../dtcc_core/schemas/model/0.5.0/schema.yaml).
See [version handling](../../../docs/design/model-naming.md#version-handling).
