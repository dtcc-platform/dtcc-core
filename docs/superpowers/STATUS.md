## What we're building

An LoD2+ building-reconstruction pipeline for `dtcc-core`, with machine learning introduced for (a) robustness of the existing rule-based pipeline and (b) broader roof-type coverage.

Full design rationale: [`specs/2026-04-18-ml-for-lod2-plus-design.md`](specs/2026-04-18-ml-for-lod2-plus-design.md).

Work is split into two tracks:

- **Track 1 — Evaluation harness (no ML).** Measures the rule-based pipeline; provides the benchmark Track 2 is judged against.
- **Track 2 — Learned roof-type classifier.** Feature-based scikit-learn classifier (Phase 1 parity, Phase 2 Tier 2 expansion).

A third area — Gemma 4 integration, raw-point-cloud classifier, roof topology graph prediction, imagery-based reconstruction — is explicitly follow-on work, not part of current scope.
